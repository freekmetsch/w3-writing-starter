# Writing 3: 15-minute start

This page offers 62 original C2 Proficiency Part 2-style tasks. It shows two different-format tasks per run. Choose one to start a 15-minute timer and see five optional words or phrases.

Each task has a 280–320-word target. The timer marks a short start, not a deadline to finish the full task. Write on paper or in your own document. The page does not save your writing.

This is not a full C2 Proficiency practice paper.
